```bash

```

## ⚙️ Usage

1. Set token-chatid in `telegram_rat.py` file
2. `python telegram_rat.py` Launch with

- 📸 Screenshot and camera
- ⌨️ Keylogger
- 🖥️ System management
- 🔐 Chrome passwords
- 💻 Shell commands
- 🔄 Autostart
